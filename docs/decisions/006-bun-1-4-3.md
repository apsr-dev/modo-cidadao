# ADR 006 — Bun 1.4.3 no projeto

Data: 20/10/2026. Durante a revisão do PR #5, o responsável confirmou a
inclusão da atualização de runtime pendente no checkout local.

O projeto exige Bun **1.4.3** em `.bun-version`, `packageManager`, `engines`,
verificador de runtime, CI e Dockerfile. A instalação do executável na
máquina é independente; esta mudança não a modifica.

Bun permanece como único runtime JavaScript da web/worker e gerenciador de
pacotes. Vite continua responsável por desenvolvimento/build. Não há
atualização de bibliotecas: `@types/bun` permanece em 1.4.2 e a instalação
usa `bun install --frozen-lockfile`, preservando `bun.lock`.

Os resultados históricos com 1.4.2 continuam registrados. As verificações
desta atualização e seus limites estão em
[VALIDACAO-PR5-REVISAO.md](../VALIDACAO-PR5-REVISAO.md).
